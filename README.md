# Sharing Board

当前版本：`V1.5.24`

Sharing Board 是一个面向局域网场景的多设备加密传输工具，可在手机、电脑和平板之间发送文字与文件。服务端只负责转发密文，不参与解密。

## 主要功能

- 扫码连接：运行后首先展示邀请二维码，其他设备进入房间后自动打开传输界面
- 统一会话：文字与文件在同一个微信文件传输助手风格界面中发送
- 多设备识别：每台设备可自定义昵称、图片头像或文字头像及颜色，并使用稳定短码区分同名设备
- 文件卡片：区分照片、视频、文档和普通文件，并按发送与接收方向排列
- 端到端加密：浏览器端使用 `PBKDF2 + AES-GCM` 加密文字和文件内容
- 稳定传输：支持文件分片、断点续传和多个文件排队发送
- 响应式界面：适配 PC、平板和移动端，可切换主题颜色和明暗模式
- 房间隔离：不同房间的内容与最近同步状态互不影响
- 局域网 HTTPS：启动时自动检查并生成自签名证书

## 技术栈

- 后端：Python, FastAPI, Uvicorn, WebSocket
- 前端：HTML, CSS, Vanilla JavaScript, Web Crypto API
- 证书：Python `cryptography`

## 使用方式

### 1. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 2. 启动服务

Windows 下直接运行：

```bat
Run.bat
```

脚本会自动：

- 安装依赖
- 检查并生成 `key.pem` / `cert.pem`
- 启动 HTTPS 服务
- 自动打开主设备页面
- 自动生成一组默认房间号和密码

### 3. 连接其他设备

- 主设备首页会显示当前房间的邀请二维码
- 使用同一局域网内的手机、电脑或平板扫描二维码
- 对方设备进入房间后，主设备会自动展开传输界面
- 展开界面后，可从右上角分享按钮再次查看二维码、复制邀请链接或调整房间设置

首次通过 HTTPS 访问时，浏览器可能因为自签名证书显示安全提示，这是预期行为。启动终端也会显示可供其他设备访问的局域网地址：

```text
https://你的局域网IP:8000
```

### 4. 发送文字与文件

- 在底部输入框粘贴或输入文字，按 `Enter` 或点击“发送”
- 点击底部文件夹图标选择一个或多个文件，文件会依次加密发送
- 自己发送的消息显示在右侧，其他设备发送的消息显示在左侧
- 接收的文件在卡片内显示“未下载”或“已下载”状态，点击类型图标即可下载
- 若发送端短暂断线，重新进入原房间后会继续补传缺失分片

### 5. 设置设备资料

- 点击传输界面右上角的设备头像，可修改设备昵称和头像
- 未选择图片时默认使用昵称首字作为文字头像
- 设备资料保存在当前浏览器中，用于在会话里区分不同发送者

## 安全说明

- 服务器只看到房间号和密文，看不到明文内容
- 密钥由浏览器端基于房间号和共享密码派生，不会上传到服务器
- 邀请二维码由本地服务生成，用于向其他设备展示加密房间接入链接
- 当前方案适合局域网内的轻量共享，不适合作为高强度涉密文件系统

## 文件传输说明

- 当前单文件大小限制为 `64 MB`
- 文件采用前端分片后逐块加密传输，默认分片大小为 `256 KB`
- 可一次选择多个文件，前端会自动排队顺序发送
- 发送过程中会在对应文件卡片内显示进度；接收完成后会显示下载状态
- 这比单条 WebSocket 消息更稳定，适合手机照片、截图、文档等中等体积文件
- 当前仍然不适合超大文件、跨天长时任务或后台持久下载
