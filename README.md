# 🔒 Secure Clipboard (安全共享剪贴板)

一个基于 **端对端加密 (E2EE)** 和 **WebSocket** 的跨平台实时剪贴板同步工具。旨在解决局域网内多设备（特别是 Windows 与 iOS/Android 之间）文本传输的隐私与便捷性问题。

## ✨ 核心特性

* **绝对隐私 (Zero-Knowledge)**：服务器仅作为“盲节点”负责密文广播，不存储、不记录、也无法解密任何通信内容。
* **端对端加密**：采用浏览器原生 `Web Crypto API` (AES-GCM 算法)，解密密钥（密码）仅保留在本地设备内存中，绝不上传。
* **跨平台无缝同步**：完美适配 Windows、macOS、iOS 和 Android 等主流操作系统。
* **极简部署**：提供 Windows 环境下的一键启动脚本，自动处理依赖库安装与本地 SSL 证书生成（突破移动端 HTTPS 限制）。

## 🛠️ 技术栈简述

* **后端服务**：Python 3, FastAPI, Uvicorn, WebSockets
* **前端界面**：HTML5, Vanilla JavaScript, CSS3 (纯原生，无冗余框架)
* **安全加密**：AES-GCM 256-bit, SHA-256 哈希
* **证书签发**：Python Cryptography 库 (自动化生成自签名本地 SSL 证书)

## 🚀 快速开始

### 1. 获取代码
在终端运行以下命令克隆仓库：
`git clone https://github.com/你的用户名/secure-clipboard.git`

### 2. 启动服务 (Windows 环境)
直接双击运行项目根目录下的 `启动.bat`。脚本将自动：
* 检查并安装所需的 Python 依赖库。
* 自动生成用于局域网 HTTPS 访问的 `key.pem` 和 `cert.pem`。
* 启动后端 WebSocket 广播服务。

### 3. 设备连接与同步
* 观察启动窗口，找到本机的局域网 IP 地址（如 `192.168.x.x`）。
* 在手机或平板的浏览器中访问 `https://192.168.x.x:8000`。
* 若浏览器提示“证书不安全”，请点击“高级”并选择“继续访问”（因使用自签名证书）。
* 在所有需要同步的设备上，输入**完全相同**的“共享密码”。
* 开始在任意设备上输入文本，即可实现毫秒级的加密同步！

## 🛡️ 安全性声明

本项目的核心设计理念是“不信任网络与服务器”。即使局域网流量被恶意截获，或者运行服务的主机被攻破，攻击者也只能获取到附加了随机 IV（初始化向量）的 AES 密文。在没有终端提取到的密码哈希的情况下，数据极难被暴力破解。
