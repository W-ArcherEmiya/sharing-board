# Sharing Board

一个面向局域网场景的加密共享板，可在多设备之间同步文字和文件。  
服务端只负责转发密文，不参与解密。

## 现在支持什么

- 房间隔离：不同房间的内容和最近一次同步状态互不影响
- 端到端加密：浏览器端使用 `PBKDF2 + AES-GCM`
- 文字同步：适合手机和电脑之间快速传文本
- 文件传输：支持常见类型文件的分片加密传输、断点续传、批量排队与下载
- 局域网 HTTPS：启动时自动生成自签名证书，兼容手机浏览器访问

## 技术栈

- 后端：Python, FastAPI, Uvicorn, WebSocket
- 前端：HTML, CSS, Vanilla JavaScript, Web Crypto API
- 证书：Python `cryptography`

## 使用方式

### 1. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 2. 启动服务

Windows 下直接运行：

```bat
Run.bat
```

脚本会自动：

- 安装依赖
- 检查并生成 `key.pem` / `cert.pem`
- 启动 HTTPS 服务
- 自动打开主设备页面
- 自动生成一组默认房间号和密码

### 3. 在其他设备访问

启动后终端会显示本机 IPv4 地址。  
在同一局域网内的其他设备打开：

```text
https://你的局域网IP:8000
```

首次访问会因为自签名证书出现安全提示，这是预期行为。

### 4. 快速接入

- 主设备页面会显示当前房间号、密码和邀请二维码
- 其他带摄像头的设备可直接扫码打开链接并自动填充接入信息
- 若设备不方便扫码，仍可手动输入房间号和密码

### 5. 开始同步

- 所有设备输入相同的房间号
- 所有设备输入相同的共享密码
- 文字会自动同步
- 文件可通过页面中的上传区一次选择多个并顺序加密发送
- 若发送端短暂断线，重新连回原房间后会自动继续补传缺失分片

## 安全说明

- 服务器只看到房间号和密文，看不到明文内容
- 密钥由浏览器端基于房间号和共享密码派生，不会上传到服务器
- 邀请二维码由本地服务生成，用于把接入链接展示给其他设备
- 当前方案适合局域网内的轻量共享，不适合作为高强度涉密文件系统

## 文件传输说明

- 当前单文件大小限制为 `64 MB`
- 文件采用前端分片后逐块加密传输，默认分片大小为 `256 KB`
- 可一次选择多个文件，前端会自动排队顺序发送
- 页面会显示上传中、续传中、中断和完成等状态
- 这比单条 WebSocket 消息更稳定，适合手机照片、截图、文档等中等体积文件
- 当前仍然不适合超大文件、跨天长时任务或后台持久下载
